# Security Policy

## Supported Versions

Only the latest release on `master` is actively maintained.

| Version | Supported |
| ------- | --------- |
| 0.11.x  | ✅        |
| < 0.11  | ❌        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them via GitHub's private [Security Advisories](../../security/advisories/new) feature.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You can expect acknowledgment within 48 hours.

## Scope

This is a local MCP server intended to run on your own machine. It is **not** designed to be exposed to the public internet. Please keep that threat model in mind when assessing issues.
